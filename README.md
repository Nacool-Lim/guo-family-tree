專為家族旅行攝影師設計的互動式人物關係誌與族譜導覽。

## 👨‍👩‍👧‍👦 家族概覽
* **總人數**：35 位
* **旅行窗口**：林致宇（我）
* **世代分佈**：
  * 🌸 第一代（大家長 / 祖父母）：2 位
  * 🟣 第二代（父母 / 舅舅 / 阿姨）：10 位
  * 🔷 第三代（平輩兄弟姐妹 / 伴侶）：17 位
  * 🟢 第四代（晚輩小朋友）：6 位

## 💡 功能特色
1. **即時搜尋**：右上角搜尋欄支援打字即時定位高亮人物。
2. **房頭切換**：可按五大房（我家、大舅房、小舅房、大姨房、二姨房）個別檢視。
3. **世代淺色系**：依世代配置柔和淺色系背景，層次分明。
4. **一鍵列印**：支援 A3/A4 橫式列印與 PDF 匯出。
